# rostric-site

Public pages for the Rostric iPhone app: privacy policy, terms of use, help and contact.
Served by GitHub Pages from the `main` branch.

The source of truth is `site/` in the (private) app repository; copy changes from there.

`icon.png` is the app icon (the scoreboard R) at 256 px; its source of record is `design/icon/app-icon-scoreboard-r.png`
in the app repository (DECISIONS D11).
